# 默认视觉：Vercel 式黑白

用户已指定：未来由本 Skill 生成的网页，默认采用 Vercel / Geist 启发的黑白设计语言。这里借鉴可迁移机制，不复制 Vercel 页面、品牌标识、三角 Logo、专有文案或完整 trade dress。

## 默认契约

- **颜色**：白色页面，近黑正文，灰阶辅助文本与边框。只使用 `background 1 / background 2` 两级表面。
- **字体**：优先 Geist / Geist Sans；离线环境未提供字体时使用系统无衬线与中文 UI 字体。数字比较启用 tabular nums；技术标签可用 Geist Mono / 系统等宽字体。
- **排版**：标题紧凑但不拥挤、负字距、无衬线、重量 600–700；正文克制，标题与正文不混用杂志宋体。拉丁 display 行高建议 `0.98–1.04`，默认 `1.02`；中日韩 display 行高建议 `1.10–1.16`，默认 `1.12`，绝不能把英文的紧行高直接套给中文。
- **网格**：页面最大宽度约 1200px，12 列网格，章节用水平细线和留白分隔。
- **容器**：圆角默认 8px，1px `#eaeaea` 边框；不使用奶油纸色、大圆角、厚重投影、玻璃效果或彩色底卡墙。
- **图表**：黑白是网页外壳，不是图表禁色令。分类、连续、发散和正负数据可使用统一的纯色色板；同时保留直接标签、线型、形状、排序或文字说明，避免颜色成为唯一编码。不要给所有色块自动铺斜线、点阵或其他纹理。
- **动效**：快速、轻微、服务状态；静态报告可完全无动效。
- **明暗**：默认浅色黑白。只有用户明确要求深色时才切换，不自动放主题按钮。

## 必须使用的 tokens

以 `assets/styles/vercel-monochrome.css` 为基准：

```css
--bg: #ffffff;
--surface: #ffffff;
--surface-2: #fafafa;
--ink: #171717;
--muted: #666666;
--rule: #eaeaea;
--rule-strong: #d4d4d4;
--accent: #000000;
--radius: 8px;
--display-leading-latin: 1.02;
--display-leading-cjk: 1.12;
--display-tracking-latin: -.065em;
--display-tracking-cjk: -.035em;
--chart-1: #2563eb;
--chart-2: #f28e2b;
--chart-3: #0f9d7a;
--chart-4: #d84a4a;
--chart-5: #8b5cf6;
--chart-6: #0891b2;
--chart-positive: #0f9d7a;
--chart-negative: #d84a4a;
```

允许根据内容调整字号、列宽和密度；除非用户指定其他主题，不得把 `--bg` 改回米白、奶油或彩色背景，也不得把 `--accent` 改成整页主色。

页面必须用 `<html lang>` 配合 `:lang(zh)` / `:lang(ja)` / `:lang(ko)`（或等价的 `:where()` 组合）切换 display 行高。中文多行 Hero 的自动审计下限为 `1.08`；默认仍为 `1.12`，移动端不得为了塞进首屏再次压紧。

## 报告组件映射

| 内容 | 默认处理 |
|---|---|
| Hero | 白底、无衬线大标题、紧字距、一个简洁 kicker 和必要 meta |
| KPI | 直接落在网格或细边框单元，不用悬浮阴影卡片 |
| 章节 | 细水平边界 + 章节标签 + 左对齐标题 |
| 图表 | 白底或 `#fafafa`、1px 边框；数据层可使用分类色、连续色阶或语义色，复杂图仍服从关系选择矩阵 |
| 表格 | 细横线、等宽/表格数字、低对比表头 |
| Callout | 完整细轮廓或黑底白字；禁止左侧彩色竖线 |
| Footer | 上边框、来源/限制，较小灰色文字 |

## 拒绝项

- 奶油纸色、墨绿 + 砖红等“编辑杂志默认配色”
- 衬线巨型 Hero 作为无条件默认
- 18–24px 大圆角与弥散阴影卡片墙
- 紫蓝渐变、彩色玻璃、发光装饰
- 用 Vercel Logo、三角符号或品牌名装饰普通报告
- 把所有图表强制成纯黑或灰阶而失去系列可区分性
- 把图表色板扩散成彩色页面背景、彩色卡片墙或装饰性渐变
- 全局开启 ECharts `aria.decal`，让每个色块都叠加纹理；纹理只能作为具体图表的显式降级方案

## 覆盖规则

用户明确指定品牌、主题、设计系统或参考图时，用户指令优先。覆盖必须写进 `report-plan.md`；未指定时始终回到本默认。
